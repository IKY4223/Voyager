# φ — golden_hour

Сайт-история в духе CRT-терминала, весь текст на английском. Старая машина в обсерватории одна уже 1618 дней.
Она всё ещё измеряет подсолнухи, раковины и спиральные галактики и считает φ. По нажатию любой клавиши
появляются ASCII-спираль золотого сечения и монолог машины с самой собой. Потом сайт переходит в светлую тему,
а в финале печатается `console.log(φ)`.

Вдохновлено подачей philia093.com, но код, текст, сюжет и визуал — свои.

## Запуск

Статика без сборки: открыть `index.html` в браузере или `python3 -m http.server`.

- `Y`, любая клавиша или тап — запустить показ.
- Пропустить лог можно только из консоли браузера (F12): там лежит записка от машины, команда `skip()`.
- Если уйти на другую вкладку, её заголовок сменится с `φ` на `…still counting`.
- `?fast` в адресе — всё в 20 раз быстрее (для тестов).
- `prefers-reduced-motion` — без анимаций, текст появляется сразу.

## Тест

```
node tests/smoke.cjs
```

Нужен Playwright с Chromium. Проходит всю историю и проверяет, что она доходит до финала без ошибок.
