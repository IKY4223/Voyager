# φ — golden_hour

Сайт-история в духе CRT-терминала, весь текст на английском. Старая машина в обсерватории одна уже 1618 дней.
Она всё ещё измеряет подсолнухи, раковины и спиральные галактики и считает φ. По нажатию любой клавиши
появляются ASCII-спираль золотого сечения и монолог машины с самой собой. Потом сайт переходит в светлую тему,
а в финале печатается `console.log(φ)`.

Вдохновлено подачей philia093.com, но код, текст, сюжет и визуал — свои.

## Запуск

Статика без сборки: открыть `index.html` в браузере или `python3 -m http.server`.

- `Y`, любая клавиша или тап — запустить показ. С этого момента играет музыка: она синтезируется в браузере (`music.js`, Web Audio), файлов нет.
- Скрытая команда для разработчика: `skip()` в консоли браузера (F12) проматывает лог. Записка в консоли о ней больше не говорит.
- Секрет: набери `1618` на белой странице в конце — откроется дневник хранителя.
- Машина помнит визиты (только в этом браузере, `localStorage`): при возвращении лог пишет, сколько прошло, и `...you came back.`
- Лог показывает твоё местное время; в финале машина иногда шепчет мысли внизу экрана и замечает падающие звёзды.
- На медленном интернете вместо пустого экрана видно `Loading 0%`…`100%`.
- Визиты 2, 3, 5, 8, 13 (Фибоначчи) отмечаются своей строкой; на 13-м машина пишет свою запись в дневник хранителя.
- В логе настоящая фаза Луны на сегодня. Клик по звезде на фоне — машина называет её.
- Превью ссылки: `og.png`. Адрес картинки в `index.html` рассчитан на GitHub Pages (`https://iky4223.github.io/Phi/og.png`).
- Если уйти на другую вкладку, её заголовок сменится с `φ` на `…still counting`.
- `?fast` в адресе — всё в 20 раз быстрее (для тестов).
- `prefers-reduced-motion` — без анимаций, текст появляется сразу.

## Тест

```
node tests/smoke.cjs
```

Нужен Playwright с Chromium. Проходит всю историю и проверяет, что она доходит до финала без ошибок.
