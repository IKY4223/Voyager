# φ

Сайт-история в виде старого терминала. Машина в обсерватории φ-lab одна уже 1618 дней. Она слушает
слабеющий сигнал Вояджера-1 и считает, как дроби Фибоначчи приближаются к φ. Смысл — приближение:
подойти ближе всех и всё равно не дойти. Весь текст на сайте английский.

Подача вдохновлена philia093.com; код, сюжет, тексты, музыка и визуал свои. Факты о Вояджерах взяты
со страниц NASA (science.nasa.gov/mission/voyager); это история, вдохновлённая реальным, а не сайт NASA.

## Запуск

Сборки нет. Открой `index.html` в браузере или подними любой статический сервер:

```
python3 -m http.server
```

Для публикации подходит GitHub Pages (Settings → Pages → ветка с сайтом, папка `/`).
Адреса картинки превью в `index.html` и ссылок в `404.html` рассчитаны на `https://iky4223.github.io/Phi/`.

## Что происходит на сайте

1. **Лог.** Машина просыпается и печатает лог: твоё местное время, живое расстояние до обоих
   Вояджеров, приближение к φ и к звезде AC+79 3888. Вернувшимся она показывает лог короче и помнит,
   сколько прошло с прошлого визита.
2. **Вопрос.** `RENDER pale_blue_dot? (Y/y)` — любая клавиша, клик или тап. С этого момента играет музыка.
3. **Небо.** ASCII-спираль золотого сечения, две расходящиеся искры Вояджеров и монолог машины.
4. **Взгляд назад.** 14 февраля 1990 года: последний снимок Земли, экран засвечивается до белого.
5. **Финал.** Полосы рассеянного света, одна бледно-голубая точка, `console.log(φ)` и бесконечные цифры φ.

### Секреты

| Где | Что сделать | Что будет |
| --- | --- | --- |
| белая страница | набрать `hello`, `keeper`, `voyager`, `earth`, `help` и другие слова | машина отвечает внизу экрана |
| белая страница | набрать `1618` | дневник хранителя |
| дневник | набрать `mail`, когда он допечатался | неотправленные письма машины |
| финал | кликнуть по голубой точке | машина говорит о Земле |
| тёмное небо | кликнуть по искре | её живое расстояние |
| консоль браузера (F12) | набрать `help` | список команд: `ls`, `cat`, `whoami`, `voyager`, `phi`, `keeper`, `uptime`, `sudo` |

Ещё: визиты 3, 5, 8, 13 отмечаются отдельной строкой, на 13-м машина дописывает дневник; после двух
минут тишины в финале машина спрашивает, здесь ли ты.

Память о визитах хранится только в браузере посетителя (`localStorage`, ключ `phi-lab`).
Сайт ничего никуда не отправляет.

## Устройство кода

Обычные скрипты без модулей и без сборки, поэтому сайт работает и с диска. Порядок загрузки
задан в `index.html`.

| Файл | За что отвечает |
| --- | --- |
| `js/core.js` | общие инструменты: паузы, память о визитах, часы, расстояния до Вояджеров |
| `js/story.js` | все тексты истории в одном месте |
| `js/terminal.js` | печать текста, прогресс-бары, проигрывание лога, вопрос про `Y` |
| `js/sky.js` | ASCII-небо на canvas: спираль с искрами Вояджеров, полосы света в финале |
| `js/music.js` | музыка: синтезируется в браузере (Web Audio), звуковых файлов нет |
| `js/ending.js` | монолог, взгляд назад, белая страница, финал с точкой, шёпот |
| `js/secrets.js` | дневник, письма и разбор того, что набирает посетитель |
| `js/console.js` | команды в консоли браузера |
| `js/main.js` | запуск |
| `style.css` | все стили |
| `404.html` | страница для несуществующих адресов |

Чтобы поменять текст, достаточно `js/story.js`. Скорость лога задаётся в `PACE` в `js/terminal.js`.

## Проверка

```
node tests/smoke.cjs
```

Нужен Playwright с Chromium. Тест проходит всю историю в 20 раз быстрее (параметр `?fast`)
и проверяет каждую возможность по разу.

Для отладки: `skip()` в консоли браузера проматывает лог до вопроса.
