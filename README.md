# φ — golden_hour

Маленький сайт-история в духе CRT-терминала: лог «пробуждения» старой обсерватории печатается вживую,
потом по нажатию любой клавиши появляется ASCII-спираль золотого сечения, стихотворение
и переход в светлую тему.

Вдохновлено подачей philia093.com, но код, текст, сюжет и визуал — свои.

## Запуск

Статика без сборки: открыть `index.html` в браузере или `python3 -m http.server`.

- `Esc` / «пропустить» — промотать лог до вопроса.
- `Y`, любая клавиша или клик — запустить показ.
- `?fast` в адресе — всё в 20 раз быстрее (для тестов).
- `prefers-reduced-motion` — без анимаций, текст появляется сразу.

## Тест

```
node tests/smoke.cjs
```

Нужен Playwright с Chromium. Проходит всю историю и проверяет, что она доходит до финала без ошибок.
